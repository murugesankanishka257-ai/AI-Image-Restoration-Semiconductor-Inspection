# AI-Based Restoration of Degraded Images for Semiconductor Inspection

## Problem Statement
Semiconductor inspection images can be affected by noise and loss of resolution.

## Our Solution
We propose an AI-based image restoration approach that removes noise, recovers lost details, and generates clean, high-quality images.

## Key Challenges
- Speckle noise
- Additive Gaussian noise
- Downsampling

## Methodology
The model is trained using paired degraded and ground-truth images to learn image restoration and preserve important image details.

## Technology
- Python
- PyTorch
- Deep Learning
- NVIDIA GPU
- Jupyter Notebook

## Evaluation
The restoration quality will be evaluated using:
- PSNR
- SSIM
- LPIPS
